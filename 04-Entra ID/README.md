# W6 – Microsoft Entra ID

## Overview

This project documents my learning and practical understanding of Microsoft Entra ID, focusing on identity management, authentication, access control, and troubleshooting.

It covers fundamental concepts, structured troubleshooting methods, and practical troubleshooting scenarios relevant to IT Support and Systems Support roles.

## Learning Objectives

- Understand Microsoft Entra ID and cloud identity management.
- Understand users, groups, and administrative roles.
- Understand authentication, Multi-Factor Authentication (MFA), and Conditional Access.
- Learn how to investigate sign-in failures using Entra ID sign-in logs.
- Apply structured troubleshooting methods to identity and access issues.
- Develop practical Service Desk troubleshooting and documentation skills.

## Learning Approach

This project combines theoretical learning with practical exercises and scenario-based troubleshooting.

Scenarios created for learning purposes are identified as simulated cases. Practical findings are documented separately to distinguish completed exercises from real-world work experience.

## Scope

This project focuses on Microsoft Entra ID fundamentals and common identity and access troubleshooting tasks. It is a learning project and does not represent production tenant administration experience.
