# 01 — Build the Lab Environment

## Purpose

Build an isolated virtual environment for practising Windows desktop support, networking, and Active Directory troubleshooting.

This section starts with the prerequisites and covers virtual machine creation, operating system installation, network configuration, domain controller setup, client configuration, and baseline verification.

## Documentation Standard

Each lab will include:

- Purpose and learning objectives
- Prerequisites and required permissions
- Devices and virtual machines involved
- A screenshot checklist before starting
- Step-by-step instructions
- Commands and expected results
- Troubleshooting guidance
- Verification and recovery steps
- Evidence filenames and privacy checks

## Safety

Use an isolated practice network and test accounts. Never publish passwords, recovery keys, licence keys, or personal information.

All labs will be marked as completed only after the instructions and verification steps have been reviewed.
