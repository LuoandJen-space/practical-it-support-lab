# Practical IT Support Lab

**A hands-on IT Support portfolio focused on Windows troubleshooting, networking, Active Directory, Entra ID, Microsoft 365, Intune, ITIL and help desk workflows.**

## About This Project

This repository documents a practical learning journey toward entry-level IT Support and Service Desk roles.

It combines reproducible technical labs, troubleshooting workflows, diagnostic scripts, evidence-based investigation, and professional support documentation.

The goal is to help learners understand not only how to perform a technical task, but also how to identify a problem, collect evidence, investigate possible causes, apply a safe fix, and verify the outcome.

## Learning Path

| Area | Topics |
|---|---|
| Windows Desktop Support | System performance, services, startup troubleshooting, Event Viewer, and Windows diagnostics |
| Networking | IPv4, DNS, DHCP, connectivity testing, and network troubleshooting |
| Active Directory | Domain controllers, domain join, users, groups, OUs, GPO, authentication, and permissions |
| Integrated Troubleshooting | End-to-end investigation across Windows, networking, identity, and resource access |
| Help Desk Operations | Ticket notes, knowledge base articles, evidence collection, and escalation |
| Diagnostic Scripts | Reusable PowerShell tools with usage instructions and example outputs |

## Lab Environment

The planned lab uses virtual machines to create an isolated practice environment.

- Hyper-V for virtualisation
- Windows Server as the domain controller
- Windows 11 Pro as the client
- An isolated virtual network for domain and troubleshooting exercises

Each lab will document its prerequisites, setup steps, expected results, verification methods, and relevant safety considerations.

## Lab Documentation Standards

Each completed lab aims to include:

- A realistic support scenario
- Step-by-step instructions
- Commands and graphical interface paths
- Expected outputs and their interpretation
- Troubleshooting branches for different results
- Resolution and verification steps
- Screenshots or other supporting evidence
- Ticket notes and relevant escalation guidance

## Project Status

This project is being developed incrementally.

Completed labs will be identified clearly. Planned topics will remain marked as planned until their instructions and verification steps have been reviewed.

## Safety and Privacy

All scenarios are intended for an authorised practice lab.

- Do not use these procedures against systems without permission.
- Do not publish passwords, access tokens, licence keys, or personal information.
- Review and redact screenshots before publication.
- Prefer read-only diagnostic steps before making configuration changes.
- Document recovery or rollback steps for changes that may affect system availability.

## Who Is This For?

- Beginners preparing for entry-level IT Support or Service Desk roles
- Learners who want hands-on Windows and networking practice
- Students building a technical portfolio
- Anyone who wants to practise structured, evidence-based troubleshooting

## Disclaimer
